# create-bread-line

Sets up [Bread Line](https://jobs.loafpickle.com), a daily remote job radar that scores job boards against your resume in Claude Code or Codex.

```
npm create bread-line@latest
```

This makes a `bread-line` folder (or the folder you name: `npm create bread-line@latest my-jobs`) and installs the engine, [@loafpickleww/bread-line](https://www.npmjs.com/package/@loafpickleww/bread-line). Then open Claude Code or Codex in the folder and say "set up Bread Line for me".
